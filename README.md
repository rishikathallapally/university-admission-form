
# University Admission Form 🎓

A responsive University Admission Form built using HTML and CSS. This project provides a clean and user-friendly interface for students to enter their personal, contact, academic and course details.

## 🌐 Live Demo https://rishikathallapally.github.io/university-admission-form/

## ✨ Features

- Clean and modern admission form design
- University campus image banner
- Personal information section
- Contact information section
- Parent / Guardian details
- Academic information
- Course selection
- Document upload fields
- HTML form validation
- Clear Form and Submit Application buttons
- Responsive layout for desktop, tablet and mobile devices
- Smaller, side-by-side buttons on mobile screens

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🚀 How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/rishikathallapally/university-admission-form.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

## 📌 Note

This is a frontend-only project built using HTML and CSS. Form submission and document storage require backend integration.
